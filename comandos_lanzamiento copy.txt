ESCENARIO 1: SIMULACIÓN (Gazebo)
1. Iniciar Gazebo y Robot

ros2 launch sancho_navigation simulation.launch.py

2. Opción A: Mapear (Crear mapa nuevo)

ros2 launch sancho_navigation slam.launch.py

3. Opción B: Navegar (Usar mapa existente)

ros2 launch sancho_navigation navigation.launch.py

4. Mover Robot (Teleoperación)

ros2 run turtlebot3_teleop teleop_keyboard

5. Guardar Mapa (Sobrescribir)

ros2 run nav2_map_server map_saver_cli -f ~/gonzalo_ws/src/sancho_navigation/maps/greenhouse_map



7. Ejecutar Patrulla Autónoma (Simulación)

ros2 run sancho_navigation greenhouse_navigator --ros-args -p execution_mode:=simulation

ESCENARIO 2: ROBOT REAL

0. Lanzar drivers robot real

ros2 launch turtlebot3_bringup robot.launch.py

1. Mapear (Crear mapa real) (Nota: Ajusta la ruta si tu usuario no es gonzalomarin)

ros2 launch sancho_navigation slam.launch.py use_sim_time:='false' params_file:=/home/gonzalomarin/gonzalo_ws/src/sancho_navigation/config/mapper_params_real.yaml

ros2 run nav2_map_server map_saver_cli -f ~/gonzalo_ws/src/sancho_navigation/maps/greenhouse_map_real

2. Navegar (Usar mapa existente)

ros2 launch sancho_navigation navigation.launch.py use_sim_time:='false'

3. Ejecutar Patrulla Autónoma (Real)

ros2 run sancho_navigation greenhouse_navigator --ros-args -p execution_mode:=real
